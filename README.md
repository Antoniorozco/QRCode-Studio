## Objetivo

QRCode Studio es una herramienta web diseñada para simplificar la creación de códigos QR utilizados en campañas de marketing, materiales impresos y procesos internos de Viamericas. La aplicación permite generar códigos QR personalizados de manera rápida desde una interfaz intuitiva.
